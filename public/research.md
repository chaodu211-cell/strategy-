## 结论

**六个策略 = 三档风险 × 两种做法。**

- **三档**按回撤预算和敞口上限分：稳健 15% / 1 倍（只用 QQQ、SOXX、PSQ 和现金，不碰任何杠杆产品），均衡 25% / 2 倍，
  进取 35% / 3 倍。挑法同一条：十年窗回撤在预算内、年化最高。
- **拟合版**：17~19 个参数（选品、杠杆、波动目标、红黄蓝点的用法、CCC 的四种用法、空头、回撤闸）随机抽 4 万组，
  按事先定好的规则挑「自己和邻居都达标、邻居年化中位数最高」的那组。
- **简明版**：只用信号研究里两段都站得住的四条规则（黄点锁仓、红点含空心清仓、CCC 走阔减半、常态持有纳指），
  参数取整数，十年窗里只调一个杠杆（1 / 1.5 / 2.5 倍）。

**我的选择：简明版，按风险偏好取 1 / 1.5 / 2.5 倍；没有特别偏好就用简明·均衡（1.5 倍）。** 理由：

1. **每一档里，简明版的 2007-16 年化都不低于拟合版，回撤都更浅**：14.2% 对 15.9%、20.3% 对 12.9%、33.0% 对 18.4%；
   −14.1% 对 −26.0%、−22.6% 对 −33.0%、−34.9% 对 −48.6%。简明版两段的成绩接近，拟合版从十年窗到 2007-16 掉了一大截
   （进取型 101% → 18%）。
2. **拟合版十年窗多出来的那一倍，主要来自这十年特有的东西**：纳指 / 半导体二选一（均衡型只做 QQQ 少 12.5 个百分点；
   上级的检验里二选一在 2007-16 每一对比较都输给只做纳指）、只认实心红点（空心红点在十年窗里拖累、在 2007-16 有用）、
   熊市闸门与 CCC 压力期空仓、蓝点抄底。十年窗挑出来的前 40 组放到 2007-16，中位数和网格里随便抽一组差不多（三档都是，第六节）。
3. **拟合版十年窗的回撤是运气好的那一面**：同样的日收益打乱重排，68%~85% 的路径回撤超预算；简明版 27%~52%。
4. **简明版对成交时点不敏感**（均衡档四种口径 25.7%~27.2%），年换手 2~4 倍，规则少到每天看一眼两个模型的页面就能执行。
5. 但要说清楚：**简明版的四条规则是看过信号研究（含 2007-16）之后定的**，它在 2007-16 的成绩同样偏乐观；
   只是拟合版在同一段上的退化远大于这个偏差能解释的。

**两个模型各管什么**

- **最优拟合是择时的主体**。等敞口消融（去掉信号后把仓位整体缩放到同样的平均敞口）里去掉它，简明·均衡十年窗
  26.2% → 16.0%、2007-16 20.3% → 11.9%。最要紧的是**黄点**（去掉后简明·均衡 2007-16 回撤 −22.6% → −44.7%），
  红点（含空心）次之；蓝点在十年窗里贡献很大（主要是解除黄点锁仓、V 形反弹里尽快回去），在 2007-16 基本没有。
- **利差模型更像一盏「波动偏高」的状态灯，单独用不是择时信号**。利差在 200 日线上方的日子，1998-2006、2007-16、
  十年窗三段的波动都高一截，收益却一段高一段低。在唯一干净的 1998-2006 里，单独用它减仓不如同样平均仓位的固定仓位，
  见顶预警还帮了倒忙（1999-11-01 亮灯后纳指又涨了 85%）；但**叠在趋势离场上**，它把回撤从 −49.5% 压到 −28.1%
  （熊市反弹里信用还紧的时候少拿一半）。信用危机里它最有用：去掉它，简明·进取 2007-16 回撤从 −34.9% 变成 −68.1%
  （2008-10 蓝点解除黄点锁仓后满仓回去，之后又跌三成）。拟合版里 CCC 见顶预警之后 63 日空仓 / 减半、压力期减仓，
  十年窗与 2007-16 两段都在压回撤。

**现实一点的预期**：拿 2007-16 和重抽样当参照，别拿十年窗。简明·均衡大致年化 20%~28%、回撤按 −25%~−30% 准备；
简明·进取年化 30%~45%、回撤按 −45% 准备；简明·稳健年化 14%~20%、回撤按 −20% 准备。

## 三、六个策略的规则

t 日收盘后判定，次日收盘成交。优先级：抄底 > 黄点锁仓 > 常态；抄底敞口低于当天常态敞口时按常态。代码 `strategy2.py`。

### 简明版（三档同一套规则，只差杠杆 L）

| 模块 | 规则 | 来自 |
|---|---|---|
| 常态 | 持有纳指 L 倍：稳健档 L = 1，直接拿 QQQ；均衡档 L = 1.5、进取档 L = 2.5，拿 TQQQ（权重 L ÷ 3），余下现金 BIL | — |
| CCC 走阔 | 利差（滞后一日）在自身 200 日线上方：敞口减半 | CCC 利差 |
| 红点 | 实心或空心红点之后 30 个交易日：空仓 | 最优拟合 |
| 黄点 | 亮起即空仓锁定，直到 TDC < 60、或纳指收复到距 52 周高点 3% 以内、或出现实心蓝点 | 最优拟合 |

L 的挑法：十年窗回撤在该档预算内的 L 里年化最高（`simple2.py`）。十年窗里 L = 0.5 / 0.75 / 1 / 1.5 / 2 / 2.5 / 3 分别是
10.3% / 14.3% / 18.4% / 26.2% / 33.6% / 41.5% / 48.6%，回撤 −7.0% / −10.4% / −13.7% / −21.0% / −27.4% / −34.3% / −39.4%
（L ≤ 1 那三档用 QQQ，其余用 TQQQ），几乎是线性的——想要别的风险水平，按比例取 L 即可。
1.5 倍也可以用 QLD 75% 实现（2 倍 ETF 满仓与 3 倍 ETF 加现金的磨损相同，上级说明里核过）。

## 局限（用之前先读）

1. **双重样本内**：红点、蓝点门槛在 2017-10 以后标定，CCC 两条规则 2026-10-23 在 2016-10 以后的数据上选定，策略参数又在同一个十年里挑。
2. **2007-16 不是干净的样本外**：黄点在 2006 年以来的回撤上设计（`趋势下跌确认.md` 第二节），空心红点是为 2007-16 的失声补的，
   本目录的信号研究看过它，简明版的四条规则又是从信号研究来的。它只能说明「策略参数」有没有过拟合，不能说明信号本身在新时代还灵。
3. **黄点没见过 2000-02 那种熊市**（成分股数据 2004 年起）。简明版的回撤控制几乎全靠它，它要是失灵，能兜底的只有 CCC 减半
   （单独用在 2000-02 不管用）——需要更多保险就加熊市闸门（第七节）。
4. **利差模型单独没有择时价值**（第五节），在这些策略里主要起「波动高时少拿」的作用。
5. **急跌躲不开**：2025-02~04、2020-09 这类下跌两个模型都看得晚，回撤只能靠杠杆水平硬扛。简明·进取的 −34.3% 就是 2025 年那一段。
6. **最优拟合的历史读数会被改写**：2026-11-10 起成分股已按在册区间取样本，名单调整带来的历史改写已消除；行情修订与计算窗口变化仍可能影响历史读数（见上级 说明.md「信号快照」），2026-09-29 起另有当时显示值的快照。
7. **流水线时点**：主口径假设信号在次日美股收盘前出来。快照记录过一次晚了三天（10-16 的信号 10-20 才写出）；遇到这种情况等于晚一天以上，
   「t+2 收盘」一列可作参照。
8. 年换手按组合权重计（1 倍档直接拿 QQQ，权重变化比拿 TQQQ 的两档大，所以换手数字反而更高）。成本加倍各策略少 0.1~1.7 个百分点。
