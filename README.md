# 双模型策略 · 回测与每日净值

[打开网站](https://chaodu211-cell.github.io/strategy-/) · [每日更新记录](https://github.com/chaodu211-cell/strategy-/actions)

读取公开的 [最优拟合模型](https://github.com/chaodu211-cell/best-weights) 和 [CCC 利差模型](https://github.com/chaodu211-cell/ccc-spread)，展示六套原研究策略、预警点位、持仓依据、自定义回测及每日模拟净值。策略净值不代表证券账户收益。

## 动量选品

自定义底层可选固定 QQQ、固定 SOXX，或 QQQ / SOXX 动量二选一。默认每月首个交易日比较 `P[t-21] / P[t-126] - 1`，较强者胜出；同分保留原选择，首次同分选 QQQ。支持观察期、剔除期、每日/每周/月度频率及百分点缓冲。自定义策略的常态和蓝点始终使用同一底层，自动选择当时可交易的最高倍数真实 ETF。信号下一交易日收盘执行。

原有六套策略参数保持原样，其中拟合版常态已有固定的月度动量规则。新增“自定义·动量”采用 `tracking/config.json` 中登记的默认参数；个人浏览器草稿只用于历史回测，不会自动上传至公开仓库。更改已登记参数需建立新策略版本，不能覆写原有跟踪账本。

## 每日跟踪

- 起点固定为 **2026-10-27**，每条策略首个完整交易日收盘净值以 **1** 为基准。首次基准继承已观测目标，不计初始入场费；之后计入真实 ETF 复权收益、BIL 收益和交易成本。
- GitHub Actions 每日北京时间 **10:17** 更新、**18:17** 重查，也支持手动运行。休市不添加收益点，调度可能延迟。
- 每条目标保存观测时间，只能在观测之后且信号日期之后的收盘成交。晚到模型不会补做过去的交易；已记录净值只追加，不按后来回写的历史模型重新计算。
- 先对既有持仓估值，再读取新目标。行情缺失时停止追加；模型缺失时保留持仓估值，暂停产生新目标，并在页面显示原因。
- 信号取模型发布页及可核验快照；CCC 额外滞后一个交易日。ETF 取 Yahoo Finance 的实际 `adjclose`，不以未复权价或模型页面显示价替代。只接纳纽约时间 16:00 收盘至少30分钟后的日线，提前收市日保守等待到同一时间。
- 可交易性沿用原研究：上市至少20个交易日，前一交易日的60日均成交额至少1000万美元（至少20个观察）。单边成本：≥5亿美元3bp、≥5000万美元8bp，否则20bp；BIL为1bp。默认再平衡带5个百分点，工具出现/消失必调仓。
- 蓝点 x 不设人为上限，额外借款按固定年利率 **5% × 实际日历天数 / 365** 计息并入负债。其他规则保持原仓位限制。无券商保证金追缴模拟，净值耗尽则报错暂停。

`tracking/state.json` 为连续账本与状态机；`tracking/evidence/` 留存每次成功计算的输入和源版本；`public/forward.json` 为页面曲线；`public/update-status.json` 为最近尝试状态。每个新点记录输入 SHA-256。历史研究数据固定截至2026-10-22，与前向跟踪分开。

## 运行与部署

无需第三方依赖，使用 Node.js 22 和 Python 3.12（需要系统根证书及网络）：

```sh
node scripts/build-pages.mjs --restore-only
node scripts/test_forward.mjs
node scripts/daily-update.mjs
node scripts/build-pages.mjs
```

大体积的公开研究 JSON 以 gzip 保存在 `seed-assets/`，构建时恢复；不包含账户信息、令牌或 Sites 私有配置。首次需在仓库 Settings → Pages 将 Source 选为 GitHub Actions。Actions 使用仓库临时 GITHUB_TOKEN 保存账本及部署，无需另设长期密钥。

日频模型输出与历史回测均不能保证未来收益，回撤筛选预算不是未来回撤上限。


## 蓝点敞口比较（2026-10-27）

自定义回测默认勾选“仅当抄底敞口不小于当日常态/锁仓敞口时执行”。先排除实心蓝点，按其他有效规则的优先级计算当天目标底层敞口（普通规则保持原有±3倍限制），再与蓝点多头/分批目标比较；相等也通过。未通过则蓝点不参加最终排序，沿用其他规则或常态；通过后仍受规则优先级约束。按带方向的目标敞口比较，空头为负，不比较ETF资金权重或漂移后的持仓。开关可关闭以回放原优先级规则，旧浏览器设置缺此字段时默认启用，须重新生成回测。敞口比较本身不改变蓝点计数；黄点是否解锁由独立解锁条件决定；每日明细与导出依据包含比较双方及结果。

已登记的每日自定义策略沿用登记版本；旧登记配置缺少该开关时，自动更新程序显式保持原来的关闭口径。浏览器新默认不会悄然改写已登记策略或历史净值。


## 黄点遇实心蓝点永久解锁（2026-10-27）

自定义黄点解锁条件新增 blueEnabled，默认 true，旧浏览器设置缺字段时也默认启用。TDC回落、QQQ价格修复、实心蓝点中任一已启用条件满足即解除；实心蓝点只在事件日触发，空心蓝点不计。解锁持续到下一个新黄点，不因蓝点40日窗口结束或TDC/价格再次恶化而重锁。黄蓝同日由新黄点先锁定，不事后回用当天蓝点。解锁先于持仓规则和抄底敞口比较，与蓝点交易操作是否开启、优先级及是否实际成交无关；实际仓位仍次一交易日收盘执行。可单独启用蓝点解锁，无需TDC或价格修复序列。每日依据记录解除日期与原因。

登记中的每日策略继续按原版本：旧登记配置缺少 blueEnabled 时显式保持 false；浏览器默认不自动改写已登记参数或净值。


## 回测图时间范围

历史图新增双端时间滑块、起止日期输入和“全部时间”恢复。原策略可在2007-01-03至2026-10-22内选择，自定义策略可在本次已生成回测内选择；至少保留两个交易日，开始日期向后、结束日期向前对齐可用交易日。选择只改变查看范围，不重新建仓或改变原交易路径，区间起点归一为1。

区间年化收益、每日收益夏普、最大回撤、回撤恢复日期、年换手率及标记同步计算，恢复只能发生在当前选区内。年换手率按当日所有ETF权重变动加一次现金权重变动计算，区间首日仅为净值基准，不重复计入首日交易。原策略逐日净值直接读取已保存的_nav2_研究CSV，不重拟合模型；逐个核对现有存档点、六套策略的12个最大回撤窗口和年化指标后，以history-daily.json发布（GitHub源码以seed-assets/public__history-daily.json.gz存储）。原策略持仓悬停定位至选区内邻近的已存档日期，自定义回测保留每日完整持仓；极短原策略区间无存档时明确提示，不能以邻日持仓冒充。

蓝点分批独立标的存储在规则的 `asset` 字段，支持 `momentum` / `QQQ` / `SOXX` / `inherit`（兼容旧设置）。动量仍在QQQ与SOXX间比较；常态固定时也可单独为蓝点启用动量，观察期等参数共用。x为底层敞口，自动使用当时可交易的最高倍数ETF。蓝点未生效、比较未通过、其他规则优先或40日窗口结束时按常态或其他有效规则执行。个人浏览器设置不会更改已登记的每日跟踪策略。

CCC见顶预警新增 `stackWithCredit` 开关，浏览器默认启用：当见顶与信用压力/高于200日线两条均为乘数操作且生效时，目标为常态敞口×见顶乘数×选中信用状态乘数。信用压力与高于200日线按优先级、同级按表序二选一，不进行三项累乘。组合取两条较高的优先级与其他规则竞争；蓝点敞口比较也使用累乘后的常态/锁仓目标。开关、持仓依据和参数导出同步保存，关闭可恢复单规则优先级。既有每日登记策略缺失此开关时明确固定为false，历史账本不变。

新增 `bear200Enabled` 自定义开关，默认关闭，缺失字段也关闭。开启时统一以QQQ复权收盘价严格低于含当日的完整200交易日简单均线判断熊市，最高优先级清仓全部权益和反向ETF，目标100% BIL；站回均线及以上后按其他有效规则或常态恢复。清仓和恢复均在次一交易日收盘执行，沿用交易成本、BIL收益；蓝点计数、黄点解锁与动量状态继续更新。均线由冻结复权收益重建相对价格，不改变历史模型信号，缺失所需行情则中止回测。图中逐日持仓记录依据、均线比值及清仓天数，导出保留开关。已登记每日策略保持关闭。

原200日线全局清仓已替换为拟合·进取熊市闸门模块：QQQ收盘低于200日均线，且该均线低于21个交易日前水平，两项同时成立才将常态多头乘以0。任一条件不满足即解除。黄点专用配置、空头及蓝点抄底不被全局清仓；蓝点比较使用闸门后的常态/锁仓目标，规则间保留自定义优先级。需要221个复权收盘，缺少所需收益时中止回测。条件已与原引擎逐日核对5266日。配置改为 `bearGateEnabled`，旧 `bear200Enabled` 布尔值自动迁移且删除旧字段，提示重新生成回测；默认关闭，既有每日登记策略保持原样。
