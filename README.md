# 双模型策略 · 回测与每日净值

[打开网站](https://chaodu211-cell.github.io/strategy-/) · [每日更新记录](https://github.com/chaodu211-cell/strategy-/actions)

读取公开的 [最优拟合模型](https://github.com/chaodu211-cell/best-weights) 和 [CCC 利差模型](https://github.com/chaodu211-cell/ccc-spread)，展示六套原研究策略、预警点位、持仓依据、自定义回测及每日模拟净值。策略净值不代表证券账户收益。

## 动量选品

自定义底层可选固定 QQQ、固定 SOXX，或 QQQ / SOXX 动量二选一。默认每月首个交易日比较 `P[t-21] / P[t-126] - 1`，较强者胜出；同分保留原选择，首次同分选 QQQ。支持观察期、剔除期、每日/每周/月度频率及百分点缓冲。自定义策略的常态和蓝点始终使用同一底层，自动选择当时可交易的最高倍数真实 ETF。信号下一交易日收盘执行。

原有六套策略参数保持原样，其中拟合版常态已有固定的月度动量规则。新增“自定义·动量”采用 `tracking/config.json` 中登记的默认参数；个人浏览器草稿只用于历史回测，不会自动上传至公开仓库。更改已登记参数需建立新策略版本，不能覆写原有跟踪账本。

## 每日跟踪

- 起点固定为 **2026-10-27**，每条策略首个完整交易日收盘净值以 **1** 为基准。首次基准继承已观测目标，不计初始入场费；之后计入真实 ETF 复权收益、BIL 收益和交易成本。
- GitHub Actions 每日北京时间 **10:17** 更新、**18:17** 重查，也支持手动运行。休市不添加收益点，调度可能延迟。
- 每条目标保存观测时间，只能在观测之后且信号日期之后的收盘成交。晚到模型不会补做过去的交易；已记录净值只追加，不按后来回写的历史模型重新计算。
- 先对既有持仓估值，再读取新目标。行情缺失时停止追加；模型缺失时保留持仓估值，暂停产生新目标，并在页面显示原因。
- 信号取模型发布页及可核验快照；CCC 额外滞后一个交易日。ETF 取 Yahoo Finance 的实际 `adjclose`，不以未复权价或模型页面显示价替代。只接纳纽约时间 16:00 收盘至少30分钟后的日线，提前收市日保守等待到同一时间。
- 可交易性沿用原研究：上市至少20个交易日，前一交易日的60日均成交额至少1000万美元（至少20个观察）。单边成本：≥5亿美元3bp、≥5000万美元8bp，否则20bp；BIL为1bp。默认再平衡带5个百分点，工具出现/消失必调仓。
- 蓝点 x 不设人为上限，额外借款按固定年利率 **5% × 实际日历天数 / 365** 计息并入负债。其他规则保持原仓位限制。无券商保证金追缴模拟，净值耗尽则报错暂停。

`tracking/state.json` 为连续账本与状态机；`tracking/evidence/` 留存每次成功计算的输入和源版本；`public/forward.json` 为页面曲线；`public/update-status.json` 为最近尝试状态。每个新点记录输入 SHA-256。历史研究数据固定截至2026-10-22，与前向跟踪分开。

## 运行与部署

无需第三方依赖，使用 Node.js 22 和 Python 3.12（需要系统根证书及网络）：

```sh
node scripts/build-pages.mjs --restore-only
node scripts/test_forward.mjs
node scripts/daily-update.mjs
node scripts/build-pages.mjs
```

大体积的公开研究 JSON 以 gzip 保存在 `seed-assets/`，构建时恢复；不包含账户信息、令牌或 Sites 私有配置。首次需在仓库 Settings → Pages 将 Source 选为 GitHub Actions。Actions 使用仓库临时 GITHUB_TOKEN 保存账本及部署，无需另设长期密钥。

日频模型输出与历史回测均不能保证未来收益，回撤筛选预算不是未来回撤上限。


## 蓝点敞口比较（2026-10-27）

自定义回测默认勾选“仅当抄底敞口不小于当日常态/锁仓敞口时执行”。先排除实心蓝点，按其他有效规则的优先级计算当天目标底层敞口（普通规则保持原有±3倍限制），再与蓝点多头/分批目标比较；相等也通过。未通过则蓝点不参加最终排序，沿用其他规则或常态；通过后仍受规则优先级约束。按带方向的目标敞口比较，空头为负，不比较ETF资金权重或漂移后的持仓。开关可关闭以回放原优先级规则，旧浏览器设置缺此字段时默认启用，须重新生成回测。比较不改变蓝点计数，不解除黄点锁定；每日明细与导出依据包含比较双方及结果。

已登记的每日自定义策略沿用登记版本；旧登记配置缺少该开关时，自动更新程序显式保持原来的关闭口径。浏览器新默认不会悄然改写已登记策略或历史净值。
