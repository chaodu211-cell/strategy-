## 动量选品

自定义回测的常态与蓝点分批都可以选择 QQQ / SOXX 动量。两个入口共用选品方法。选择动量后，右侧可选以下方法，旧设置默认采用综合方法。

| 选品方法 | 月度动量 | 相对走弱确认 | 长债过滤 |
| --- | --- | --- | --- |
| 月度动量 | ✓ | | |
| 相对走弱确认 | ✓ | ✓ | |
| 长债过滤 | ✓ | | ✓ |
| 综合方法 | ✓ | ✓ | ✓ |

1. 月初首个交易日比较复权涨幅 `P[t-21] / P[t-126] - 1`。对手严格更高才换，同分保留上次月度选择，首次同分选 QQQ。
2. SOXX / QQQ 复权价比的 21 日及 63 日涨幅同时为负时判定走弱。月首检查动量选中的 SOXX。月内在每周首个交易日检查进入当日时选中的 SOXX。综合方法在长债过滤解除当天也复查走弱。触发后锁定 QQQ 至下月首个交易日。月首与周首重合时执行月首规则。
3. DGS30 按 ETF 交易日对齐，联储节假日沿用前值。每日用 `t-1` 与 `t-127` 的收益率计算基点变化。达到 50 bp 开启过滤，低于 40 bp 关闭，所需观测缺失时延续前一日状态。开启时将 SOXX 改选为 QQQ。 [FRED DGS30](https://fred.stlouisfed.org/series/DGS30)

只有月度动量选 SOXX 且通过所选方法启用的过滤时才选 SOXX。目标在信号次一交易日收盘执行。选品方法随设置保存和导出，逐日图表和 CSV 包含选品依据。浏览器草稿可导出用于登记新的每日跟踪版本。

回测使用 `public/dgs30.json` 的冻结数据。恢复历史输入后可运行 `node scripts/dgs30.mjs` 重新获取快照。选品方法启用长债过滤时必须提供 DGS30 数据，缺少数据或某日输入未提供会直接报错，不会静默关闭长债过滤。每日登记版本启用长债过滤时，跟踪程序只把已发布的滞后收益率写入账本；FRED 尚未发布或暂不可用的日期本次按缺值处理（延续前一日过滤状态）并给出警告，下次运行重新获取。

## 每日跟踪

- 起点固定为 **2026-10-27**，每条策略首个完整交易日收盘净值以 **1** 为基准。首次基准继承已观测目标，不计初始入场费；之后计入真实 ETF 复权收益、BIL 收益和交易成本。
- GitHub Actions 每日北京时间 **10:17** 更新、**18:17** 重查，也支持手动运行。休市不添加收益点，调度可能延迟。
- 每条目标保存观测时间，只能在观测之后且信号日期之后的收盘成交。晚到模型不会补做过去的交易；已记录净值只追加，不按后来回写的历史模型重新计算。
- 先对既有持仓估值，再读取新目标。行情缺失时停止追加；模型缺失时保留持仓估值，暂停产生新目标，并在页面显示原因。
- 信号取模型发布页及可核验快照；CCC 额外滞后一个交易日。ETF 取 Yahoo Finance 的实际 `adjclose`，不以未复权价或模型页面显示价替代。只接纳纽约时间 16:00 收盘至少30分钟后的日线，提前收市日保守等待到同一时间。
- 可交易性沿用原研究：上市至少20个交易日，前一交易日的60日均成交额至少1000万美元（至少20个观察）。单边成本：≥5亿美元3bp、≥5000万美元8bp，否则20bp；BIL为1bp。默认再平衡带5个百分点，工具出现/消失必调仓。
- 蓝点 x 不设人为上限，额外借款按固定年利率 **5% × 实际日历天数 / 365** 计息并入负债。其他规则保持原仓位限制。无券商保证金追缴模拟，净值耗尽则报错暂停。

`tracking/state.json` 为连续账本与状态机；`tracking/evidence/` 留存每次成功计算的输入和源版本；`public/forward.json` 为页面曲线；`public/update-status.json` 为最近尝试状态。每个新点记录输入 SHA-256。历史研究数据固定截至2026-10-22，与前向跟踪分开。

## 蓝点敞口比较（2026-10-27）

自定义回测默认勾选“仅当抄底敞口不小于当日常态/锁仓敞口时执行”。先排除实心蓝点，按其他有效规则的优先级计算当天目标底层敞口（普通规则保持原有±3倍限制），再与蓝点多头/分批目标比较；相等也通过。未通过则蓝点不参加最终排序，沿用其他规则或常态；通过后仍受规则优先级约束。按带方向的目标敞口比较，空头为负，不比较ETF资金权重或漂移后的持仓。开关可关闭以回放原优先级规则，旧浏览器设置缺此字段时默认启用，须重新生成回测。敞口比较本身不改变蓝点计数；黄点是否解锁由独立解锁条件决定；每日明细与导出依据包含比较双方及结果。

已登记的每日自定义策略沿用登记版本；旧登记配置缺少该开关时，自动更新程序显式保持原来的关闭口径。浏览器新默认不会悄然改写已登记策略或历史净值。


## 黄点遇实心蓝点永久解锁（2026-10-27）

自定义黄点解锁条件新增 blueEnabled，默认 true，旧浏览器设置缺字段时也默认启用。TDC回落、QQQ价格修复、实心蓝点中任一已启用条件满足即解除；实心蓝点只在事件日触发，空心蓝点不计。解锁持续到下一个新黄点，不因蓝点40日窗口结束或TDC/价格再次恶化而重锁。黄蓝同日由新黄点先锁定，不事后回用当天蓝点。解锁先于持仓规则和抄底敞口比较，与蓝点交易操作是否开启、优先级及是否实际成交无关；实际仓位仍次一交易日收盘执行。可单独启用蓝点解锁，无需TDC或价格修复序列。每日依据记录解除日期与原因。

登记中的每日策略继续按原版本：旧登记配置缺少 blueEnabled 时显式保持 false；浏览器默认不自动改写已登记参数或净值。

## CCC压力位蓝点限制（2026-11-05）

自定义回测新增独立开关 `cccStressBlueLimitEnabled`，默认关闭，旧设置缺少此字段时也保持关闭。开启后，仅当已有CCC极端压力状态成立（252日历史分位≥95）时，在原策略选品、优先级和蓝点抄底之后，对全部最终多头目标施加上限：

`最终多头目标 = min(原策略可实现目标, 3倍, 50% / 当日默认标的的10日年化实现波动率)`

**监测标的由当日常态底层决定**：常态QQQ监测QQQ，常态SOXX监测SOXX，常态动量配置跟随当天QQQ/SOXX选品结果。即使蓝点独立选择了另一标的，波动率来源也保持为当日常态底层。例如常态QQQ、蓝点SOXX时监测QQQ；常态动量选中SOXX时监测SOXX。使用含信号日的最近10个复权日收益的样本标准差（ddof=1）×√252，不使用杠杆ETF自身波动率。

本层不会提高较小的原目标，也不改变空仓或空头目标。波动率回落时上限随之提高；CCC极端压力解除时撤除此层上限，目标按其余有效规则恢复，不等待账户净值修复。上限约束的是目标敞口；实际持仓继续遵循信号次日收盘成交、CCC额外一日滞后、原再平衡带、成本和融资规则。

网页公式、当前监测提示、调仓依据及CSV中的监测标的、波动率、上限和限仓结果保持同一口径。勾选后重新生成回测，配置随JSON导出；浏览器设置不会自动修改已登记策略或已记录净值。

`node scripts/test_forward.mjs` 已纳入专项测试，覆盖常态/蓝点不同标的、常态动量换品、蓝点高优先级不能绕过最终限制、10日样本波动率、只在CCC极端压力时启用、次日成交、压力解除、融资权重及旧设置兼容。


## 自定义回撤闸（同拟合·进取）

新增 `drawdownGateEnabled` 开关，默认关闭，旧配置缺失时保持关闭。参考净值从其历史峰值回撤达到20%时，常态多头目标乘0.5；回撤修复到10%以内解除。仅减半常态多头及按常态执行的预警多头，保留蓝点、黄点专用配置、空头与空仓。蓝点敞口比较先使用回撤闸处理后的常态目标，再按自定义优先级选择；CCC压力位蓝点限制在最后对全部最终多头封顶。

为保持拟合·进取口径，回撤闸参考净值自历史数据首日起，以前一信号日最终目标ETF权重和当日复权收益连续累计；包括蓝点、空头及CCC封顶后的目标反馈，不计BIL收益、交易成本、融资利息及实际再平衡漂移。它与图中实际组合净值分别显示。切换回测日期不重置参考状态，信号次一交易日收盘执行，实际成交继续遵循原再平衡带。

回测摘要记录触发状态日数和实际减半目标日数；持仓依据与逐日CSV包含参考净值、峰值、参考回撤和本次是否减半，配置JSON保留开关。修改设置后重新生成回测应用；浏览器设置不自动更改每日登记策略与原账本。参考收益缺失或参考净值耗尽时明确报错，不伪造有效状态。

`node scripts/test_drawdown_gate.mjs` 覆盖20%/10%边界、次日成交、蓝点覆盖、CCC最终封顶和目标反馈、黄点及空头保留、日期切片不重置、无前视和旧配置兼容；另与原拟合增量引擎逐日核对5486日参考净值、触发状态及目标敞口。此测试已纳入每日验证套件。

## 熊市闸门方法：四类投票（E2，2026-11-09）

自定义回测的熊市闸门新增 `bearGateMethod`：`ensemble`（四类投票，浏览器新设置默认）或 `ma200`（原拟合·进取口径：QQQ低于200日线且均线低于21日前，常态多头×0）。旧设置、导出文件和已登记策略缺少该字段时一律按 `ma200` 执行，校验时不补写字段，历史回测与账本不变。

四类投票每天用QQQ复权收盘价计算18个子信号，按四类分组：

| 类别 | 看空条件 | 参数 | 判断频率 |
|---|---|---|---|

乘数 = 四类各自看多比例的等权平均（0~1）。常态多头及按常态执行的规则多头乘以该乘数，余款持有BIL；黄点专用配置、空头与蓝点抄底不受影响，蓝点敞口比较使用闸门后的常态目标。乘数为0时状态记为“熊市闸门”，介于0与1之间时记为“原状态 · 熊市闸门×乘数”。历史不足的子信号暂按看多计；缺少QQQ或BIL有效收益时报错，不静默关闭。信号次一交易日收盘成交。
