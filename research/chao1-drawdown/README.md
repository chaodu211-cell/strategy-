# Chao#1 的极端行情回撤控制（2026-11-09）

问题：Chao#1 应该怎样控制极端行情回撤——加熊市闸门限制杠杆、用 CCC 压力位蓝点限制、两者一起，还是有更适合它的办法？

研究对象是 2026-11-09 上传的设置 `chao1-settings.json`（动量常态 3 倍、蓝点 4 倍 / 10 次 / 40 日跟随常态标的、CCC 压力位蓝点限制开、再平衡带 25%）。
网站引擎在冻结面板 + DGS30 快照上逐位复现了它：全期 2007-01-03 → 2026-10-22 年化 66.9%、最大回撤 −39.4%、夏普 1.41。
所有数字由 `run.mjs` 生成（完整输出 `results.md`）。研究用的引擎副本只在内存里加挂钩，不改动网站代码，无挂钩时与网站引擎逐日一致。

```sh
node scripts/build-pages.mjs --restore-only
node research/chao1-drawdown/run.mjs     # 约 13 秒
```

---

## 结论

1. **CCC 压力位蓝点限制必须保留。** 关掉它，2008 段回撤从 −38.3% 变成 −70.6%（蓝点 4 倍加融资）。
2. **不要加熊市闸门，「两者一起」是三个选项里最差的。** Chao#1 在熊市里的常态本来就被 CCC 状态压到 1.5 倍，熊市闸门把它清零，
   2008 段确实降到 −24.9%，但也让 2016 年 2~5 月、2009 年春这类熊市反弹全部空仓：熊市闸门 + 蓝点熊市上限 + CCC 限制，
   全期 66.9% → 55.1%，最大回撤反而 −39.4% → −40.6%（2015-16 窗口 −26.8% → −40.6%）。
   我上次给拟合·进取的「蓝点熊市上限 1 倍」在这里单独用效果有限（2008 段 −38.3% → −35.8%，年化少 1.7 个百分点）：你的蓝点有「不低于常态才执行」的比较，
   熊市里上限 1 倍的蓝点会输给常态的 1.5 倍，最多把仓位压回 1.5 倍；下面的 x = 3 用更小的代价取得同样的 2008 改善，还顺带改善了 2010、2011、2020。
3. **更适合你的改法：蓝点 x 从 4 改成 3（抄底不借钱）。** 全期 66.9% → 65.5%，夏普 1.41 → 1.42，融资天数 107 → 0；
   2008 段 −38.3% → −35.8%，2010 段 −34.0% → −26.5%，2011 段 −35.0% → −30.6%，2020 段 −18.3% → −13.9%；
   全样本重抽样回撤超 40% 的路径 59% → 54%。x = 2.5~3.5 是一片平台，x = 5 全面变差。
   道理：常态已是 3 倍时，蓝点只有超过 3 倍才会被选中，多出来的那 1 倍全靠借钱；2010-06（4.27 倍）、2011-10~11（4 倍）就亏在这借来的一倍上。
   而蓝点又恰恰是两个模型里样本外最弱的信号（十年窗蓝点后 40 日 +88.5%，2007-16 只有 +4.5%，见 `public/research.md` 第一节）。
4. **你现在的最大回撤 −39.4% 不是「极端行情」，是 2025 年 2~3 月满仓 3 倍的急跌**：2024-12-16 高点到 2025-03-12 黄点亮起，
   满仓 TQQQ 亏了 37.9%，红点、CCC 都没响应。这类急跌（2020-09 −35.4%、2018-02 −32.9%、2012-09 −31.9%）任何慢速闸门都看不到。
   我补测了 MA50 / MA100 / MA200 和「QQQ 距高点 −8% / −12%」五种急跌过滤，**全部被「直接降常态杠杆」支配**：
   例如 MA200 减半 55.1% / −36.6%、夏普 1.31，而常态 2.5 倍是 56.3% / −34.3%、夏普 1.42。急跌风险就是 3 倍杠杆的 beta，择时过滤来回打脸亏掉的比省下的多。
5. **要压最大回撤，就转常态杠杆这个旋钮**（x = 3 时）：

   | 常态 | 全期 | 十年窗 | 全样本重抽样：回撤超 40% / 超 50% |
   |---|---|---|---|
   | 3 倍 | 65.5% / −39.4% | 84.8% / −39.4% | 54.0% / 12.8% |
   | 2.75 倍 | 61.2% / −36.9% | 78.8% / −36.9% | 42.5% / 8.2% |
   | 2.5 倍 | 56.3% / −34.3% | 73.6% / −34.3% | 28.8% / 4.2% |

   夏普在 2.5 倍以上都是 1.42，往下才开始降。
6. **注意：每日跟踪中的已登记版本 `custom-chao-1` 不是这份设置。** 它是常态 QQQ、蓝点 SOXX 4 倍、CCC 限制关闭（登记早于该功能，缺字段按关闭），
   同一套冻结数据上全期 48.9% / **−83.0%**（2008 段 −83.0%）。上传的这份要好得多；想跟踪它（或改了 x 之后的版本），需要按规则登记新版本。

## 一、回撤从哪里来

四类来源：① 常态 3 倍遇急跌（最大的一段）；② 蓝点 4 倍遇非熊市、多半也非 CCC 压力的回调（CCC 限制管不到）；
③ 熊市里常态仍拿 1.5 倍（2008 蓝点解锁后、2022 下半年）；④ 熊市中 CCC 压力暂时解除时蓝点不受限（2008-12-30 → 2009-01-20 2.4 倍）。
另外：2025-04-03 一个实心蓝点就永久解除了黄点锁仓，此时梯子只有 0.4 倍，比较后落回常态 1.5 倍，次日在暴跌中重新入场——这次只多亏了约 2.7%，未作为建议测试。

## 二、预登记

候选、评估和挑选规则在跑变体之前写下（写时已看过上表和熊市闸门、回撤闸两个现成开关的单独结果）：
用户的三个选项（熊市闸门 + 蓝点熊市上限；CCC 限制现状；两者一起），全时段波动上限 V（所有多头 ≤ b/σ10，b = 0.5 / 0.75 / 1.0，另 σ20），
只对蓝点的全时段波动上限 VB，蓝点 x = 3 / 3.5，回撤闸开关，常态 2.5 倍对照。
挑选规则：全期最大回撤 ≤ 35% 且年化代价 ≤ 10 个百分点者中取年化最高，邻居同样满足，2008 / 2020 / 2022 / 2025 不变差 3 个百分点以上。

**结果：没有任何候选满足。** 能把全期回撤压到 35% 左右的只有降常态杠杆（x = 3 + 常态 2.5 倍：−34.3%，代价 10.6 个百分点，略超上限）；回撤闸 −35.8%、代价 21.5 个百分点。
原因是全期最大回撤来自 2025 年的急跌，而候选里除了降杠杆都不针对它。所以下面的建议分两层：x = 3 改善所有危机窗口、几乎不花钱；
要压最大回撤，只能用常态杠杆换。

## 三、熊市闸门为什么在 Chao#1 里不划算

熊市闸门只清零常态多头（不管蓝点、黄点和空头），Chao#1 熊市里的常态是 CCC 状态给的 1.5 倍。清零后 2008 和 2022 少亏，
但 2016 年 1 月底到 5 月 QQQ 在下行的 200 日线下方反弹，闸门版一直空仓并反复开关（现状同期净值 25 → 34，闸门版 17 → 15），
随后 Brexit 两天 SOXL 3 倍 −26.8%，于是 2015-16 窗口回撤 −40.6%，全期最大回撤反而变深。
原研究里熊市闸门对拟合·进取也是同样的两面：十年窗压回撤，2007-16 减收益（去掉后 2007-16 年化 15.9% → 20.7%，见 `public/research.md` 第六节），在 Chao#1 里代价更大。

## 四、建议

1. 保留 CCC 压力位蓝点限制。
2. 蓝点 x 改为 3。
3. 不加熊市闸门，也不加蓝点熊市上限；不用均线 / 距高点类择时过滤。
4. 能接受 −40% 左右的回撤就停在常态 3 倍；要 −35% 左右，常态 2.5 倍（年化约少 9 个百分点）。
5. 可选：蓝点标的固定 QQQ（历史上无差别，避免将来在 SOXX 上 3 倍抄底）。
6. 以上都是网页上的现有设置，不需要改代码。已登记的 `custom-chao-1` 不能改写，要跟踪新设置需导出后登记为新版本（新 ID，从登记后首个收盘以 1 起算）。

## 局限

1. 写候选前已看过回撤表；x = 3 的依据主要是机制（借来的杠杆加在样本外最弱的信号上）和邻居平台，不是单个回测数字。
2. 全样本只有一次 2008 型信用危机；2010 以前的 3 倍 ETF 是合成序列。
3. 回测没有券商保证金追缴；x = 4 时 107 天有融资负债，实盘的追保风险比回测更大——这也是 x = 3 的一个额外理由。
4. 最优拟合的历史读数会被改写，CCC 另滞后一日（见 `public/research.md` 局限）。
