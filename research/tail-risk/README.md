# 拟合·进取的极端行情回撤：诊断与优化（2026-11-09）

问题：拟合·进取在 2007-16 最大回撤 −48.6%（2008），缺乏极端行情的回撤控制，应如何优化？

本目录只做研究，**不改动六套原策略、不改写已登记的前向账本**。所有数字由 `run.mjs` 在冻结研究面板上生成（完整输出见 `results.md`）。
`run.mjs` 先断言：用 `lib/live-engine.js` 的 `stepStrategy` 从 2005 年逐日重放，六套原策略在 4982 个交易日上与 `public/history-daily.json`
的日收益一致（误差 < 1e-9），拟合·进取四个窗口的指标与 `public/research.md` 完全相同。

```sh
node scripts/build-pages.mjs --restore-only   # 恢复冻结面板
node research/tail-risk/run.mjs               # 约 6 秒；写 results.md
```

## 结论

1. **2008 的 −48.6% 全部来自蓝点抄底通道，不是常态仓位。** 2007-11 黄点锁仓持 0.5 倍空头，净值从 1.08 涨到 1.33；2008-10-07 雷曼之后出现实心蓝点，
   抄底以优先级最高的身份接管：永久解除黄点锁仓，并**绕过了熊市闸门（×0）、CCC 压力（×0）、回撤闸（×0.5）三层风控**——这三层只乘在常态通道上。
   蓝点唯一的约束是 `min(1, 50% ÷ 10 日波动)`，而它只在 10 日波动超过 50% 时才起作用：2008-11-11 QQQ 10 日波动短暂回落到 45.7%（60 日波动 57.9%），
   门控放行满仓 3 倍，随后 6 个交易日净值 1.071 → 0.776。2008-11-04 → 11-20 −48.6%，同期 QQQ −24.3%。
2. **修法：熊市闸门亮时，蓝点抄底不加杠杆（上限 1 倍）。** 用的是策略已有的熊市闸门（QQQ 低于 200 日线且 200 日线低于 21 个交易日前），只加一个参数。

   | | 十年窗 | 2007-16 | 2008 段内回撤 | 全期 2007-2026 | 全样本重抽样：回撤超 50% 的路径 |
   |---|---|---|---|---|---|
   | 现行拟合·进取 | 94.1% / −30.5% | 15.9% / −48.6% | −48.6% | 50.4% / −48.6% | 30.3% |
   | **熊市抄底上限 1 倍（推荐）** | **89.6% / −30.5%** | **18.7% / −46.9%** | **−25.7%** | **50.4% / −46.9%** | **20.7%** |

   十年窗年化少 4.5 个百分点、回撤不变；2007-16 年化反而多 2.8 个百分点；全期年化不变。2008 段剩下的 −25.7% 是 1 倍敞口跟随 QQQ 下跌，属于不加杠杆的正常风险。
3. **为什么是熊市闸门**：蓝点的大额收益都发生在「牛市里的急跌」（2020-02 入场 +44%、2025-04 入场 +56%，入场时 200 日线还在上行）；
   入场时熊市闸门已亮的几段（2008-10、2018-12、2022-06、2022-09）是在已经确立的熊市里抄底，最好的一段 +21.5%，最差的一段就是 2008。
   熊市闸门也是上级研究里唯一在 1990-2006 完全样本外验证过的一层（见 `public/research.md` 第七节）。
4. **不要做的**：换慢速波动估计（C）、让回撤闸覆盖抄底（D）、熊市里不让蓝点解锁黄点（E）几乎压不住 2008；
   和自定义回测已有的「CCC 压力位蓝点限制」（B）叠加没有额外的尾部收益，只多付代价。
5. **只修 2008，2007-16 的最大回撤只从 −48.6% 变到 −46.9%**：下一深的 2015-16（−46.9%）和 2011（−45.0%）来自常态通道的固定 3 倍
   （常拿 SOXL、CCC 压力反复开关、2015-08-24 闪崩时持 2.25 倍 TQQQ 四天 −23%）。叠加波动预算或二级回撤闸都压不住，只会损失收益；
   能压住的只有降低常态杠杆——这是风险偏好的选择，不是风控漏洞（见第五节）。

## 二、预登记（运行任何变体之前写下）

目标、候选、评估与挑选规则在看任何变体结果之前写定，此后未改。写候选时已经知道 2008 是问题、看过上面两张表，
所以 **2007-16 对本问题不是样本外**。

- **A 熊市抄底上限**：信号日熊市闸门亮时，抄底敞口 ≤ L。主值 L = 1；邻居 0 / 0.5 / 1.5 / 2。
- **B CCC 压力组合波动预算**：CCC 分位 ≥ 95 时，抄底敞口 ≤ 0.5 / σ10（即自定义回测已有的 `cccStressBlueLimit` 公式）。邻居：预算 0.4 / 0.6；窗口 20。
- **C 慢速波动门控**：抄底门控中的 σ10 改为 max(σ10, σ60)。邻居：max(σ10, σ40)、max(σ10, σ20)。
- **D 回撤闸覆盖抄底**：回撤闸触发时抄底也 ×0.5。
- E（探索，不参与挑选）熊市闸门亮时蓝点不解除黄点锁仓。
- 次要（常态通道）：F 常态基准 ≤ V / σ20（V = 0.6 / 0.75 / 0.9）；G 参考净值回撤 ≤ −30% 时再 ×0.5。
- **挑选规则**：在 A~D 中选新参数最少、只用现有指标、且主值同时满足：① 2008 段内回撤回到 35% 预算以内；② 十年窗年化 ≥ 85%、回撤 ≤ 35%；
  ③ 邻居基本同样满足 ①；④ 其他危机窗口的回撤恶化不超过 5 个百分点。都不满足就如实报告，不再追加候选。

两者都是一个新参数、都只用现有指标，按副作用取 A：B 的代价集中在 2020 年（前五年 80.6% → 72.7%，2020 年 +231% → +165%），
2007-16 年化也没有改善；A 不碰 2020，2007-16 年化 +2.8 个百分点，全样本重抽样年化中位 50.6% 对 B 的 48.4%，尾部相同。

B 有效正是因为它把预算改成了**组合**波动（敞口 × σ ≤ 50%）。D 不够：回撤闸要等参考净值先跌 20% 才触发（2008-11-11 信号日），
减半后抄底仍有 1.2~1.5 倍，2008 段 −39.4%，回不到预算。

十年窗 4.5 个百分点的代价几乎都在这里。

**事后变体 A'（看过 2025 之后才提出，不是预登记结果）**：按本轮蓝点窗口首个实心蓝点当天的熊市状态锁定整段。
十年窗 93.7% / −30.5%、2007-16 19.5% / −46.9%、2008 段 −25.7%，2025 不受影响。但它有自己的漏洞：如果蓝点在熊市确立前开始、之后每隔不到
40 天续一次，整段会一直按「非熊市」放行 3 倍，直到窗口断开——2008 恰好没有这样走，不代表下一次不会。它的十年窗数字因为是事后挑的，偏乐观。

这类下跌开始前波动很低，波动预算事前看不到；二级回撤闸又太晚。能压住的只有常态杠杆：**要让 2007-16 也守住 35% 预算，需要 A + 常态 2 倍**，
十年窗年化降到 68%。这是要不要继续当「进取」的选择。

## 六、建议

1. **采用 A：熊市闸门亮时，实心蓝点抄底敞口上限 1 倍。** 在 `stepStrategy` 里是一行：门控之后 `if (market.bear) Eb = Math.min(Eb, 1);`，其余规则不变。
2. **按版本规则落地**：原有六套策略与已登记账本不能改写。可以 (a) 在自定义回测加一个开关（现有 `bearGateEnabled` 明确不约束蓝点，可新增
   「熊市闸门亮时抄底上限 x 倍」，默认关闭），或 (b) 登记一个新版本（如「拟合·进取·熊市抄底不加杠杆」），从登记后首个收盘起前向跟踪。
3. 想要 2025 那 45 个百分点，可以把 A' 作为第二个版本一起前向跟踪，但不要只上 A'。
4. 不要叠加 B（CCC 压力位蓝点限制）：尾部没有额外改善。
5. 如果「2007-16 回撤 ≤ 35%」是硬约束，A 不够，需要同时把常态降到 2 倍左右；否则按 −45%~−50% 准备 2015-16 那类回撤。

## 局限

1. 2007-16 不是样本外：写候选前已知道 2008 是问题、看过蓝点逐段表。证据只有 4 段熊市中的蓝点抄底，其中大的只有 2008 一段；
   采用 A 的主要理由是机制（熊市闸门已在 1990-2006 样本外验证过，熊市反弹与牛市急跌后的修复是两类行情），不是回测数字。
2. A 不管「牛市里第一跌」：2010-06、2011-08 两段入场时都不是熊市，段内回撤 −26.5%、−27.1%，仍只靠 10 日波动门控。
3. 急跌（2020-09、2025-02~03）里常态 3 倍的 −30% 回撤不受影响，这是进取档的设计。
4. 2010 年以前的 3 倍 ETF 是研究合成序列；最优拟合的历史读数会被改写（见 `public/research.md` 局限第 6 条）。
